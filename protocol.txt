Protocol Commands

Authentication Commands

- cmdGetNonce (0x01): Request authentication nonce
  - Input: pubkey(32)
  - Output: nonce(32)
- cmdAuth (0x02): Authenticate connection
  - Input: pubkey(32) + nonce(32) + signature(64)
  - Output: Success/Error
- cmdPing (0x03): Keep-alive ping
  - Input: None
  - Output: Success
  - Requires: Authentication

Chat Management Commands

- cmdCreateChat (0x10): Create new chat room
  - Input: owner_pubkey(32) + nonce(32) + counter(4) + signature(64) + name(str) + description(str) + avatar(blob)
  - Output: chat_id(u64)
  - Requires: Authentication
- cmdDeleteChat (0x11): Delete chat room (owner only)
  - Input: chat_id(u64)
  - Output: Success byte
  - Requires: Authentication, Owner permission

User Management Commands

- cmdAddUser (0x20): Add/invite user to chat
  - Input: chat_id(u64) + user_pubkey(32)
  - Output: Success
  - Requires: Authentication, Owner/Admin/Mod permission
- cmdDeleteUser (0x21): Ban user from chat
  - Input: chat_id(u64) + user_pubkey(32)
  - Output: Success
  - Requires: Authentication, Owner/Admin/Mod permission
- cmdLeaveChat (0x22): Leave chat room
  - Input: chat_id(u64)
  - Output: Success
  - Requires: Authentication; cannot be owner
- cmdGetUserChats (0x23): Get list of user's chats
  - Input: None
  - Output: count(u32) + [chat_id(u64)...]
  - Requires: Authentication

Message Commands

- cmdSendMessage (0x30): Send message to chat
  - Input: chat_id(u64) + guid(u64) + blob
  - Output: message_id(u64)
  - Requires: Authentication, Not banned, Not read-only
- cmdDeleteMessage (0x31): Delete message (moderator action)
  - Input: chat_id(u64) + message_id(u64)
  - Output: Success
  - Requires: Authentication, Owner/Admin/Mod permission
- cmdGotMessage (0x32): Server → Client notification (live message)
  - Payload: chat_id(u64) + message_id(u64) + guid(u64) + author(32) + blob_len(u32) + blob
  - Broadcast to subscribed users (including system messages)
  - Note: System messages have mediator's public key as author
- cmdGetLastMessageID (0x33): Get last message ID in chat
  - Input: chat_id(u64)
  - Output: last_id(u64)
  - Requires: Authentication, Chat membership
  - Note: Rarely needed as cmdSubscribe now returns last_message_id
- cmdSubscribe (0x35): Subscribe to live messages
  - Input: chat_id(u64)
  - Output: last_message_id(u64)
  - Requires: Authentication, Not banned, Not read-only
  - Note: Returns last_message_id to avoid separate cmdGetLastMessageID call
- cmdGetMessagesSince (0x36): Batch fetch messages since ID
  - Input: chat_id(u64) + since_id(u64)
  - Output: count(u32) + repeated: [msg_id(u64)][guid(u64)][author(32)][blob_len(u32)][blob]
  - Requires: Authentication, Chat membership
  - Note: Messages expire after 24 hours (cache TTL)

Member Info Commands

- cmdUpdateMemberInfo (0x50): Client sends encrypted member info (nickname, info, avatar)
  - Input: chat_id(u64) + timestamp(u64) + encrypted_blob(blob)
  - Output: Success
- cmdRequestMemberInfo (0x51): Server requests member info from client
  - Payload: chat_id(u64) + last_update(u64)
- cmdGetMembersInfo (0x52): Client requests members info (snapshot/incremental)
  - Input: chat_id(u64) + since_timestamp(u64)
  - Output: count(u32) + repeated: [pubkey(32)][infoLen(u32)][encryptedInfo][timestamp(u64)]
- cmdGetMembers (0x53): Get list of member public keys (lightweight)
  - Input: chat_id(u64)
  - Output: count(u32) + [pubkey(32)...]
- cmdGotMemberInfo (0x54): Server → Client notification (member info updated)
  - Payload: same as cmdGetMembersInfo but with count=1
  - Broadcast to subscribed users on member info change

System Event Codes

System messages are delivered via cmdGotMessage (0x32) with the mediator's public key as author.
The message blob format is: [event_code(u8)][event_data...]

Event codes:
  - 0x01 sysUserAdded:      [target_user(32)][actor(32)][rand(32)]
  - 0x02 sysUserEntered:    [user(32)][rand(32)] (reserved)
  - 0x03 sysUserLeft:       [user(32)][rand(32)]
  - 0x04 sysUserBanned:     [target_user(32)][actor(32)][rand(32)]
  - 0x05 sysChatDeleted:    [actor(32)][rand(32)]
  - 0x06 sysChatInfoChange: [name(str)][desc(str)][avatar(blob)]
  - 0x07 sysPermsChanged:   [target_user(32)][new_perms(u32)][actor(32)][rand(32)]

Random tail: The 32-byte random at the end serves as extra entropy for future shared-key
updates/derivations. Clients should treat it as opaque and preserve it.

Invite Commands

- cmdSendInvite (0x40): Send invite to user
  - Input: to_pubkey(32) + chat_id(u64) + encrypted_data(blob)
  - Output: Success
  - Requires: Authentication, Owner/Admin/Mod permission
- cmdGotInvite (0x41): Server → Client notification (invite delivery)
  - Payload: invite_id(u64) + chat_id(u64) + from_pubkey(32) + timestamp(u64) + chat_name(str) + chat_desc(str) + chat_avatar(blob) + encrypted_data(blob)
  - Delivered asynchronously by mediator
- cmdInviteResponse (0x42): Client responds to invite (accept/reject)
  - Input: invite_id(u64) + accepted(u8)
  - Output: Success

Permission Bits

- 0x80 - Owner: Chat creator, full control
- 0x40 - Admin: Administrative privileges
- 0x20 - Moderator: Can moderate users/messages
- 0x10 - User: Regular participant
- 0x08 - Read-only: Cannot post messages
- 0x01 - Banned: Explicitly blocked

Database Tables

Global Tables

- nonces: Authentication nonces
- chats: Chat registry
- invites: Pending invitations (auto-cleanup after 3 days)

Per-Chat Tables

- settings-{id}: Chat metadata (name, description, avatar, perms_flags)
- users-{id}: Members and roles (pubkey, text_rank, perms_flags, accepted_at, changed_at, banned, info)
- messages-{id}: Message metadata (id, ts, guid, author) - includes both user and system messages

Background Services

- Invite Cleanup Worker: Deletes invites older than 3 days
- HybridCache: RAM (Ristretto) + Disk (Badger) caching for message (author+blob)

Wire Protocol Format

Request Frame:
[version:1=0x01][cmd:1][reqId:2][len:4][payload:len]

Response Frame:
[status:1 (0=OK,1=ERR)][reqId:2][len:4][payload:len]

Data Types:
- u64/u32/u16: Big-endian integers
- string: [u16 len][bytes]
- blob: [u32 len][bytes]
- pubkey: 32 bytes (Ed25519)
- signature: 64 bytes (Ed25519)
